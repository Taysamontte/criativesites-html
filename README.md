# 🌐 Criação de Sites para Pequenas Empresas


## 📖 Sobre o Projeto
Este é um projeto de estudo desenvolvido com **HTML**, com o objetivo de criar um site simples que oferece serviços de criação de sites para pequenas empresas.  

O site inclui:  
- Cabeçalho com menu de navegação (`<header>` e `<nav>`);
- Seções de apresentação do serviço (`<section>` e `<main>`);
- Informações adicionais sobre a empresa (`<aside>`);
- Rodapé com contatos e links importantes (`<footer>`).  

O projeto foi criado como parte de uma atividade escolar para praticar estruturação de páginas web utilizando apenas HTML.

## 🛠 Tecnologias Utilizadas
- **HTML5**: Estrutura e semântica do site.
- **Comentários HTML**: Para organização do código e explicações.
- **Elementos semânticos**: `<header>`, `<nav>`, `<main>`, `<section>`, `<aside>`, `<footer>`.

## 🎯 Aprendizado
Com este projeto, aprendi a:  
- Estruturar um site utilizando tags semânticas;
- Organizar o conteúdo de forma clara para o usuário;
- Utilizar comentários no código para facilitar entendimento e manutenção.
